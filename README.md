# Blog Writer

주제 입력 → Claude 웹 검색 딥서칭 → 글쓰기 규칙에 맞춘 글 작성(본문 공백 포함 3,000자 이내) → 검토 → 크롬의 **Claude in Chrome** 확장 프로그램으로 블로그에 입력 후 **임시저장**. 발행은 사용자가 직접 합니다.

## 실행
```bash
claude                 # 한 번 로그인해 둔 Claude Code 필요 (API 키 불필요)
npm run dev            # http://localhost:5173 (API: 3001)
```
블로그 작성과 Gemini·ChatGPT 이미지 생성은 **Claude in Chrome** 확장 프로그램(https://claude.ai/chrome)으로 평소 쓰는 크롬에서 진행합니다.
1. 크롬에 확장 프로그램을 설치하고 Claude Code와 같은 Claude 계정으로 로그인합니다 (처음이면 크롬을 껐다 켭니다).
2. 그 크롬에서 블로그(와 Gemini/ChatGPT)에 로그인해 둡니다.
3. 앱의 "설정 → Claude in Chrome → 연결 확인"으로 연결을 확인합니다.

Claude가 화면을 보며 조작하므로 작업이 끝날 때까지 Claude가 연 탭 그룹은 건드리지 마세요.

## Claude 호출 방식
로컬 `claude -p` CLI를 자식 프로세스로 실행합니다 (구독 한도 사용, API 과금 없음). 딥서칭은 WebSearch/WebFetch만 허용하고 MCP/파일 툴은 끕니다.

- **모델**: "설정 → Claude 모델 설정"에서 단계마다 Fable·Opus·Sonnet·Haiku 중에서 고릅니다. 기본값은 단계별 추천 모델입니다: 자료 조사·글 작성은 **Opus**(정확도·문장 품질), 이미지(SVG)·브라우저 조작·주제 추천은 **Sonnet**(속도·한도 절약). "Claude Code 설정"을 고르면 `.env`의 `CLAUDE_MODEL`, 없으면 Claude Code에 설정된 모델을 씁니다.
- **사용량**: "사용량" 화면에서 플랜 한도(5시간·주간 사용률, 계정 전체)와 이 앱이 쓴 토큰(오늘·이번 주·최근 7일, 모델별·단계별)을 봅니다. 호출 기록은 `data/usage.jsonl`(90일 보관), 마지막 한도 값은 `data/plan-limits.json`에 저장됩니다. "지금 확인"은 Haiku로 아주 짧은 요청을 한 번 보내 최신 한도를 받아 옵니다.

### Claude in Chrome이 막는 블로그 (예: 네이버)
Claude in Chrome은 안전 정책에 따라 일부 사이트 접속을 막습니다("This site is not allowed due to safety restrictions"). 이 앱은 그 제한을 우회하지 않고 다른 방법으로 올립니다. 처음 막히면 그 자리에서 이어서 진행하고 `data/blocked-sites.json`에 기억해 다음부터는 바로 그 방법으로 합니다.

- **네이버 블로그 (macOS)**: 평소 쓰는 크롬에 새 탭을 열고 AppleScript로 그 탭에 스크립트를 넣어 SmartEditor ONE에 붙여넣기 이벤트로 입력합니다 (`server/browser/userChrome.ts`). 이미 로그인된 크롬을 쓰므로 새 창·로그인이 필요 없습니다.
  - 크롬 메뉴 **보기 > 개발자 > Apple Events의 자바스크립트 허용**을 켜 두세요.
  - 처음 한 번 macOS가 "Google Chrome 제어" 허용을 물으면 허용하세요 (시스템 설정 > 개인정보 보호 및 보안 > 자동화).
  - 이미지는 JPEG(가로 최대 1600px)로 줄여 붙여넣고, 소제목은 에디터의 "소제목" 서식으로 바꿉니다.
- **그 밖의 블로그 / 다른 OS**: 예전 자동 조작(앱 전용 크롬 `data/chrome-profile`, `server/browser/adapters.ts`)으로 올립니다. 그 크롬은 평소 크롬과 따로라 "설정 → Claude in Chrome → 2. 확장이 막는 블로그 → 네이버/티스토리 로그인 창 열기"로 한 번 로그인해 두세요.

## 지원 블로그
네이버 블로그 / 티스토리 / 워드프레스.

- **네이버·티스토리**: 크롬으로 글쓰기 화면을 조작해 **임시저장**까지만 합니다.
- **워드프레스**: 크롬 없이 **REST API**로 올립니다. 올릴 때마다 **임시저장 / 예약발행 / 자동발행** 중에서 고릅니다 (예약·자동은 확인 창을 거칩니다). 같은 글을 다시 올리면 새 글을 만들지 않고 이미 올린 글을 갱신합니다.
  1. 설정의 "워드프레스 설정" 카드에 사이트 주소(`https://...`)를 넣어 저장합니다. https 사이트만 쓸 수 있습니다.
  2. wp-admin → 사용자 → 프로필 → "애플리케이션 비밀번호"에서 비밀번호를 만들고, 설정 → 워드프레스 설정에 사용자명과 함께 넣어 "연결 확인 후 저장"을 누릅니다. 값은 `data/secrets.json`(본인만 읽기)에만 저장됩니다.
  3. 카테고리를 하나 고를 수 있습니다 (비우면 사이트 기본 카테고리). 태그는 이름으로 찾고 없으면 만듭니다.
  - 보안 플러그인이나 호스팅이 REST API 또는 애플리케이션 비밀번호를 막으면 연결되지 않습니다. 글쓴이 권한이 있는 사용자여야 하고, 자동발행·예약발행은 "발행" 권한(편집자 이상)이 필요합니다.

## 이미지 생성
새 작업 폼에서 썸네일 생성 여부, 본문 이미지 개수(0~6), 생성 방식을 고릅니다. 썸네일과 본문 이미지는 서로 다른 AI·스타일로 만들 수 있습니다(예: 썸네일은 Claude 플랫, 본문은 Gemini 실사). 처음에는 둘이 같은 값을 따라가고, 썸네일을 직접 바꾸면 따로 움직입니다. 초안 화면에서도 "썸네일 다시 만들기…"와 "이미지 모두 다시 만들기…"에서 각각 AI를 고를 수 있습니다.
- **Claude**: SVG 일러스트/인포그래픽을 그려 PNG로 렌더링 (도형·다이어그램 스타일)
- **Gemini / ChatGPT**: Claude in Chrome이 평소 쓰는 크롬에서 웹 화면을 조작해 생성 (API 과금 없음, 각 서비스 한도 + Claude 사용량). 받은 이미지는 다운로드 폴더(`DOWNLOADS_DIR`로 변경 가능)에서 가져옵니다.

스타일은 지브리풍 / 실사 / 애니메이션 / 플랫 일러스트 중에서 고릅니다. Claude(SVG)는 플랫 일러스트만 가능하고, 나머지는 Gemini·ChatGPT에서 선택할 수 있습니다. 모든 이미지에는 "근거 본문"(그 이미지가 그리는 문장)이 기록되어 초안 화면에서 확인할 수 있습니다.

**본문 기반 기획:** 이미지를 만들기 직전에 Claude가 본문을 다시 읽고, 이미지마다 그것이 놓인 섹션(소제목과 그 아래 내용)의 구체적인 대상·상황·수치가 보이도록 설명(prompt)을 쓰고 이미지 안에 넣을 문구(headline)를 정합니다. 만드는 AI(Claude는 한국어, Gemini·ChatGPT는 영어)와 스타일에 맞게 다시 써서, AI를 바꿔 다시 만들어도 본문과 맞습니다.
- 썸네일: 클릭을 부르는 8~16자 문구를 가운데에 크게 넣습니다. 본문 이미지: 도움이 될 때만 짧은 제목·라벨(수치, 단계 이름)을 넣습니다. 문구는 본문에 있는 사실로만 만듭니다.
- 초안 편집 화면에서 이미지 설명이나 문구를 직접 고치면 그 이미지는 다시 만들 때 자동으로 바꾸지 않습니다("본문을 보고 자동으로 다시 정하게 하기"로 되돌릴 수 있음).
- 이미지 속 한글은 AI가 틀리게 그릴 수 있으니 발행 전에 확인하세요. 틀리면 해당 이미지만 다시 만들거나 Claude(SVG)로 만드세요.

생성된 파일은 `data/images/<jobId>/`에 저장되고 블로그 작성 시 에디터(워드프레스는 미디어 라이브러리)에 업로드됩니다. 썸네일은 네이버·티스토리에서는 본문 첫 이미지, 워드프레스에서는 대표 이미지로 설정됩니다.

## 글쓰기 규칙
화면의 "글쓰기 규칙"에서 수정합니다. 기본값은 `rules/default-writing-rules.md`, 수정본은 `data/writing-rules.md`에 저장되며 다음 작업부터 적용됩니다.

## 주제 추천
"주제 추천"에서 분야를 입력하면 최근 2주 뉴스와 최근 발표된 통계·공고를 찾아 주제 후보 10~12개를 만듭니다.
NAVER API HUB 검색어 트렌드 키(NCP 콘솔에서 발급, 설정 → 네이버 데이터랩 설정)를 넣으면 최근 4주 검색 관심도와 상승세로 순위를 매깁니다.
관심도는 분야 대표 검색어의 평균을 100으로 놓은 상대값입니다. "이 주제로 글쓰기"를 누르면 주제와 근거 링크가 새 작업 입력란에 채워집니다.

## 태그 수집
리서치에서 정한 키워드로 네이버 **자동완성**과 **함께 많이 찾는**(예전 연관검색어 자리)을 수집해 태그 후보로 씁니다.
함께 많이 찾는은 공개 API가 아니라 검색 화면 내부 요청이라 바뀔 수 있고, 네이버가 검색어별로 꺼 두면 비어 있습니다.
수집 목록에 없는 표현을 출처로 단 태그는 서버가 빼고 로그에 남깁니다. 스마트블록 주제는 수집하지 않습니다.

## 네이버 참고
- 소제목은 에디터의 "소제목" 서식으로 입력합니다 (메뉴를 못 찾으면 굵은 글씨로 대체).
- 태그는 발행 창에서만 입력할 수 있어 본문 마지막 줄에 `#태그`로 넣습니다.

## 저장 위치 (모두 로컬 파일)
- `data/settings.json` 블로그 설정
- `data/images/<id>/` 생성된 이미지
- `data/jobs/<id>.json` 주제, 리서치 노트, 출처, 초안, 로그

## 블로그 작성·이미지 생성이 실패하면
Claude in Chrome에 주는 안내는 `server/browser/blogPost.ts`(블로그별 에디터 안내)와 `server/images/webAi.ts`(Gemini/ChatGPT)에 있습니다. 진행 로그에 Claude가 한 동작이 남고, 크롬에는 Claude가 연 탭이 그대로 남아 있어 어디서 멈췄는지 볼 수 있습니다.
