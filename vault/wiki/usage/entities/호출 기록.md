# 호출 기록 (UsageRecord)

## 의미
Claude 호출 하나(모델별로 한 줄)의 토큰과 금액이다. `data/usage.jsonl`에 한 줄씩 덧붙인다.

## 속성
| 속성 | 의미 |
|---|---|
| `at`, `stage`, `jobId?` | 시각, 호출 단계(research/writing/images/browser/recommend/check), 어느 글의 호출인지 |
| `callId` | 같은 호출에서 나온 여러 모델 줄을 한 호출로 세기 위한 id(예전 기록엔 없음) |
| `model` | 실제 쓰인 모델 |
| `input`, `output`, `cacheRead`, `cacheWrite` | 토큰 |
| `costUSD` | API 정가 환산 금액 |
