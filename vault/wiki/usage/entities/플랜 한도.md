# 플랜 한도 (PlanLimits)

## 의미
구독 플랜의 사용률(계정 전체 기준)이다. Claude를 호출할 때 CLI가 보내는 `rate_limit_event`에서 마지막 값만 `data/plan-limits.json`에 둔다.

## 속성
| 속성 | 의미 |
|---|---|
| `fiveHour`, `sevenDay` | 창별 `utilization`(0~1)과 `resetsAt`(초기화 시각 ISO) |
| `status` | allowed / allowed_warning / rejected 등 |
| `checkedAt` | 마지막 확인 시각 |
