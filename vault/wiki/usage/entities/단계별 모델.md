# 단계별 모델 (StageModels)

## 의미
Claude를 호출하는 단계마다 고른 모델이다. 설정(`settings.models`)에 저장된다.

## 속성
| 단계 | 하는 일 | 추천(기본) 모델 |
|---|---|---|
| `research` | 자료 조사 | opus |
| `writing` | 글 작성·고치기·제목·네이버 주제 | opus |
| `images` | 이미지 기획·SVG | sonnet |
| `browser` | 블로그 작성(Claude in Chrome)·웹 AI 이미지 | sonnet |
| `recommend` | 주제 추천 | sonnet |
| `check` | 한도 확인용 짧은 호출(설정과 무관) | haiku 고정 |

선택지: `default`(Claude Code 기본 또는 `.env`의 `CLAUDE_MODEL`), `fable`, `opus`, `sonnet`, `haiku`.
