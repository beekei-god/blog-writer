# 사용량 확인 플로우

## 목적
Claude 플랜 한도(계정 전체)와 이 앱이 쓴 토큰을 보고, 단계별 모델을 조정할 근거를 얻는다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 상단 칩: 60초마다, 진행 중 작업 수가 바뀔 때마다 `GET /api/usage` (Claude 호출 없음) | `App` | [[usage/business-rules/BR-USG-005 한도 경고 단계]] |
| 2 | 사용량 화면: 15초마다 `GET /api/usage` | `Usage` | |
| 3 | 서버: 기록 읽기 + 한도 파일 읽기 → 집계 | `getUsageSummary` | [[usage/business-rules/BR-USG-004 사용량 집계 기준]] |
| 4 | "지금 확인" → `POST /usage/check`: Haiku로 짧은 호출 → rate_limit_event로 한도 저장 → 요약 반환 (동시 1회) | `server/routes/usage.ts` | [[usage/business-rules/BR-USG-002 모델 결정 순서]] |
| 5 | 표시: 한도 미터, 오늘·이번 주 토큰, 7일 막대(표로 보기), 단계별 설정·마지막 모델·이번 주 토큰·호출, 모델별 토큰·정가 환산 | `Usage` | [[usage/business-rules/BR-USG-001 단계별 추천 모델]] |
| 6 | 작업 상세의 "Claude 사용": 그 작업의 모델별 토큰 | `JobUsage`(`src/job/JobUsage.tsx`), `GET /jobs/:id/usage` | |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 아직 한도 값 없음 | plan null | "아직 확인한 값이 없습니다…" |
| 확인 중 다시 누름 | 409 | "이미 확인 중입니다." |
| Claude 호출 실패 | 500 | 오류 문구 |
