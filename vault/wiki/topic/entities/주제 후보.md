# 주제 후보 (TopicCandidate)

## 의미
추천된 글 주제 하나와 그 근거다.

## 속성
| 속성 | 의미 |
|---|---|
| `topic` | 글 하나로 답할 수 있는 구체적 주제 |
| `keywords` | 네이버에 실제로 칠 만한 짧은 검색어 1~3개 |
| `reason` | 왜 지금인지 2~3문장 |
| `evidence[]` | 근거: 제목, URL(http/https만), 날짜(모르면 비움), 종류 news/stat/official |
| `autocompleteCount` | 첫 키워드의 자동완성 개수 |
| `interest` | 데이터랩 관심도: `level`(기준 평균=100 환산 평균), `momentum`(최근 7일 증감 %), `series`(일별 값) |
