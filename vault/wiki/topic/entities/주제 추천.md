# 주제 추천 (Recommendation)

## 의미
분야 하나에 대한 추천 한 번의 기록이다. `data/recommendations/<id>.json`에 저장된다.

## 속성
| 속성 | 의미 |
|---|---|
| `field` | 입력한 분야(2~100자) |
| `status` | running / done / failed |
| `anchorKeyword` | 데이터랩 비교 기준 키워드(분야 대표 검색어) |
| `datalab` | ok / not_configured / failed / pending |
| `period` | 데이터랩 조회 기간 |
| `candidates` | [[topic/entities/주제 후보]][] |
| `logs`, `error` | 진행 로그, 오류 |

## 상태 / 수명주기
running → done 또는 failed(중지 포함, "사용자가 추천을 중지했습니다"). 서버 재시작 때 running은 failed("서버가 재시작되어 중단되었습니다")로 바뀐다.
