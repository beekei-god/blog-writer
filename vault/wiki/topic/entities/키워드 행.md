# 키워드 행 (KeywordRow)

## 의미
키워드 탐색 결과의 한 줄이다. 한 덩어리(`KeywordSection`: 입력한 키워드 / 지금 뜨는 검색어 / 최근 주제 추천의 분야)에 여러 줄이 든다.

## 속성
| 속성 | 의미 |
|---|---|
| `keyword` | 연관 키워드 |
| `total`, `pc`, `mobile` | 월간 검색량(합계, PC, 모바일) |
| `lowPc`, `lowMobile` | 검색량이 "< 10"으로만 나온 쪽(실제 0~9, 5로 계산) |
| `competition` | 광고 입찰 경쟁: 낮음·중간·높음·알 수 없음 |
| `seed` | 입력한 키워드 자신인지 |
| `trend` | 지금 뜨는 검색어에도 있으면 구글 대략 검색 규모("200+") |
