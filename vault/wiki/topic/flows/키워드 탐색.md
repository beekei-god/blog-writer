# 키워드 탐색

## 목적
쓸 글의 키워드가 얼마나 검색되는지, 연관 키워드는 무엇인지 본다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 입력 검사(200자), 검색광고 키 확인 | `routes/keywords.ts` | [[topic/business-rules/BR-TOP-006 키워드 탐색]] |
| 2a | 입력 있음: 최대 5개 키워드의 연관 키워드 조회 | `lookupKeywords` | BR-TOP-006 |
| 2b | 입력 없음: 구글 트렌드 상위 10개 + 최근 추천 분야 기준으로 각각 조회 | `exploreWithoutInput` | [[topic/business-rules/BR-TOP-007 지금 뜨는 검색어]] |
| 3 | 검색량 큰 순 200개를 덩어리별로 응답 | `toRows` | |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 키 없음 | 400 | 키를 연결하라는 안내 |
| 입력·기준 모두 없음 | 400 | 키워드를 입력하거나 주제 추천을 해 보라는 안내 |
| 검색광고 오류 | 400/502 | 오류 문구 |
