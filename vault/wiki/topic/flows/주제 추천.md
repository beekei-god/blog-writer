# 주제 추천

## 목적
분야 하나에서 지금 쓸 만한 주제 후보를 근거와 검색 관심도와 함께 순위로 받는다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 분야 검사, 동시 실행 방지, 기록 파일 생성(202) | `startRecommendation` | [[topic/business-rules/BR-TOP-005 추천은 한 번에 하나]] |
| 2 | Claude + 웹 검색으로 후보와 근거 | `run` | [[topic/business-rules/BR-TOP-001 근거 있는 후보만]], [[topic/business-rules/BR-TOP-002 이미 쓴 글과 겹치지 않기]] |
| 3 | 후보별 자동완성 개수 | `naverAutocomplete` | [[topic/business-rules/BR-TOP-003 자동완성 수요 신호]] |
| 4 | 데이터랩 관심도 비교(기준 키워드 대비) | `compareInterest` | [[topic/business-rules/BR-TOP-004 데이터랩 관심도와 순위]] |
| 5 | 데이터랩이 성공했을 때만 level → momentum으로 정렬 | `run` | BR-TOP-004 |
| 6 | `done` 저장 | `update` | |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 데이터랩 키 없음 | 비교 건너뜀, 순위 없음 | "설정에서 키를 넣어 주세요" 로그 |
| 데이터랩 실패 | `datalab=failed`, 후보는 유지 | 실패 로그 |
| Claude 실패/중지 | `failed` + 오류 | 오류 문구 |
