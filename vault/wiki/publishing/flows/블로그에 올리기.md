# 블로그에 올리기

## 목적
초안을 선택한 블로그에 임시저장·예약발행·즉시발행으로 올리고, 그 블로그의 상태를 기록한다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 요청 검사(초안·진행 중·블로그 ID·연결·예약 시각) | `routes/jobs.ts` | [[publishing/business-rules/BR-PUB-002 올리기 전 조건]], [[publishing/business-rules/BR-PUB-003 예약 시각 규칙]] |
| 2 | 작업 `posting` 표시, 마지막 카테고리 기억, 백그라운드 시작(202) | `markBusy`, `saveLastCategory` | [[publishing/business-rules/BR-PUB-007 카테고리와 네이버 주제]] |
| 3 | 워드프레스면 API 경로로 분기 | `runPost` | [[publishing/flows/워드프레스 등록]] |
| 4 | 네이버 + 발행(비임시저장): 글 내용으로 주제 선택 | `pickNaverTopic` | BR-PUB-007 |
| 5 | 브라우저 큐에 넣어 하나씩 실행 | `enqueueBrowser` | [[publishing/business-rules/BR-PUB-005 크롬 방식 선택과 막힌 사이트]] |
| 6 | 막힌 사이트가 아니면 Claude in Chrome으로 입력·임시저장, 막히면 대체 방법 | `doPost` | BR-PUB-005, [[publishing/business-rules/BR-PUB-008 본문 변환과 붙여넣기 형식]] |
| 7 | 예약/즉시면 발행 창 단계 실행 | `publish.ts` | [[publishing/business-rules/BR-PUB-004 임시저장 우선과 발행 단계 실패]] |
| 8 | 그 블로그 상태 기록(posted/scheduled/published), 작업은 `draft_ready` | `setBlogStatus` | [[publishing/business-rules/BR-PUB-001 블로그별 글 상태]] |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 발행 창 필수 단계 실패 | 임시저장 상태 유지 + 이유 | 오류와 로그의 화면 구조 |
| 크롬 입력 중 실패 | 작업 `draft_ready` + 오류 | "크롬에 일부만 들어갔을 수 있으니 확인하세요" |
| 사용자 중지 | 오류 없이 초안 상태로 | "블로그 작성을 중지했습니다" |
| 확장 프로그램 미연결 | 안내 문구(ChromeExtensionError) | 설정 → Claude in Chrome 확인 |
