# 블로그별 상태 (BlogStates)

## 의미
한 글이 각 블로그(naver / tistory / wordpress)에서 어느 단계인지를 담는다. 작업의 `blogs` 필드이며, 블로그가 없으면 "올리지 않음(초안검토)"이다.

## 속성
| 값 | 화면 | 의미 |
|---|---|---|
| (없음) | 초안검토 | 아직 올리지 않음 |
| `posting` (작업 상태 + `postingTo`) | 올리는 중 | 지금 그 블로그에 올리는 중 |
| `posted` | 임시저장 | 임시저장됨(발행 단계에서 멈춘 경우 포함) |
| `scheduled` (+`scheduledAt`, 모르면 null) | 발행예약 | 예약됨 |
| `published` | 발행완료 | 발행됨 |

각 항목은 `{ status, at, scheduledAt? }`. 앞선 순서는 posted(1) < scheduled(2) < published(3)이고 `furthestBlogStatus`가 가장 앞선 것을 고른다(진행 단계 표시용).

## 상태 / 수명주기
올리기가 끝나면 작업 `status`는 항상 `draft_ready`로 돌아오고 블로그 상태만 바뀐다. 예전 글(작업 상태가 posted/scheduled/published)은 읽을 때 변환한다: 발행완료 → 네이버·워드프레스 둘 다 발행완료, 임시저장·예약 → 마지막으로 올린 블로그(없으면 워드프레스 기록이 있으면 워드프레스, 아니면 네이버). 예약 시각이 없는 예전 예약 글은 `2026-10-11 05:00(한국)`으로 채운다(사용자가 알려 준 값).
