# 워드프레스 기록 (WordPressRecord)

## 의미
워드프레스에 올린 결과를 작업에 남긴 것이다. 같은 글을 다시 올릴 때 새 글을 만들지 않고 **갱신**하고, 이미 올린 이미지를 다시 올리지 않기 위해 쓴다.

## 속성
| 속성 | 의미 |
|---|---|
| `postId` | 사이트의 글 ID |
| `link` | 글 주소 |
| `mode` | 마지막 올림 방식(draft/schedule/publish) |
| `scheduledAt` | 예약 시각(예약일 때) |
| `mediaIds` | 이미지 파일명 → 사이트 미디어(ID, URL) |
