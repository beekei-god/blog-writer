# 블로그 설정

## 의미
블로그에 올리는 데 필요한 값이다. 설정 파일(`data/settings.json`)에 블로그별 ID/주소를 두고, 올릴 때마다 블로그를 직접 고른다(**기본 블로그는 없다**). 비밀 값(워드프레스 앱 비밀번호, 이미지 API 키)은 별도 `data/secrets.json`에 있고 이 wiki는 키 이름만 다룬다 → [[_system/configuration]].

## 속성
| 속성 | 의미 |
|---|---|
| `naverBlogId` / `tistoryBlogId` | 블로그 ID (글쓰기 주소를 만드는 데 사용) |
| `wordpressUrl` | 사이트 주소(https). `wordpressSiteOf`로 읽음 |
| 카테고리 기억 | 네이버·티스토리는 에디터에서 읽은 목록(블로그 ID가 바뀌면 없는 것으로 봄), 블로그마다 마지막에 고른 카테고리 → 다음에 처음 값 (`data/categories.json`) |
| 차단 사이트 | Claude in Chrome이 막은 블로그 (`data/blocked-sites.json`) → [[publishing/business-rules/BR-PUB-005 크롬 방식 선택과 막힌 사이트]] |

`settingsFor(settings, platform)`가 고른 블로그의 ID가 들어간 설정을 만든다. 예전 설정의 기본 블로그(`platform`)와 `blogId`는 읽을 때 블로그별 값으로 옮기고 버린다.
