# 블로그 설정 (Settings)

## 의미
앱 전체 설정 하나. 블로그 쪽은 **블로그마다 따로** 연결 값을 둔다(기본 블로그 없음). 글을 올릴 때마다 어느 블로그에 올릴지 고른다 → [[publishing/business-rules/BR-PUB-015 올릴 블로그는 글마다 선택]]. 같은 객체에 이미지 기본값과 단계별 모델도 들어 있다.

## 속성
| 속성 | 타입 | 의미 | 화면 표시 |
|---|---|---|---|
| `naverBlogId` | string ≤200, 선택 | 네이버 블로그 ID (blog.naver.com/**myblog**) | "네이버 블로그 설정" 카드 |
| `tistoryBlogId` | string ≤200, 선택 | 티스토리 블로그 이름 (**myblog**.tistory.com) | "티스토리 설정" 카드 |
| `wordpressUrl` | string ≤200, 선택 | 워드프레스 사이트 주소 (https) | "워드프레스 설정" 카드 |
| `wordpressCategoryId` | 양의 정수, 선택 | 워드프레스에 올릴 때 넣을 카테고리 (없으면 사이트 기본) | 워드프레스 카드의 카테고리 선택 (연결 후 사이트에서 목록을 불러옴) |
| `images` | ImageOptions | 새 작업 이미지 기본값 → [[image/entities/ImageOptions]] | 새 글 폼 |
| `models` | StageModels | 단계별 Claude 모델 → [[usage/business-rules/BR-USG-001 단계별 추천 모델]] | "Claude 모델 설정" 카드 |

글을 올릴 때는 고른 블로그를 채운 `PostSettings`(= Settings + `platform` + `blogId`)를 만들어 크롬 입력 코드에 넘긴다 (`settingsFor`, `blogIdOf`).

**워드프레스 인증 정보**(사용자명, Application Password)는 설정 파일이 아니라 비밀 파일(`data/secrets.json`, 권한 0600)에 따로 둔다. 화면에는 연결 여부와 사용자명만 돌려준다. 예전 WordPress.com 계정 연결 값(`wpcomToken`, `wpcomUsername`)은 더 쓰지 않으며 워드프레스 연결을 저장·삭제할 때 같이 지운다.

기본값: 블로그 값 없음, 썸네일 켬·본문 0장·Claude·플랫, 추천 모델 (`blog-writer:server/store.ts:19-22`).

## 예전 설정 옮기기
예전에는 기본 블로그 `platform`과 그 블로그의 `blogId` 하나만 있었다. 설정을 읽을 때 옮기고 예전 키(`platform`, `blogId`, `mouseSpeed`)는 버린다. 이미 블로그별 값이 있으면 덮어쓰지 않는다.

| 예전 값 | 옮기는 곳 |
|---|---|
| `platform: tistory` | `tistoryBlogId` |
| `platform: wordpress`, `blogId`가 주소 형태 | `wordpressUrl` |
| `platform: wordpress`, `blogId`가 `^[\w-]+$` (단순 ID) | `naverBlogId` (워드프레스를 고르기 전에 쓰던 네이버 ID로 봄) |
| 그 밖 (`naver` 또는 없음) | `naverBlogId` |

## 상태와 전이
- 블로그마다 "● 설정됨 (<값>)" / "○ 설정 안 됨". 워드프레스는 사이트 주소와 별도로 "● 연결됨 (<사용자명>)" / "○ 연결 안 됨".
- 연결된 블로그가 하나도 없으면 "블로그가 아직 연결되지 않았습니다" 안내, 설정 탭에 빨간 점 (`blog-writer:src/App.tsx:100-116`, `:172-177`).
- 설정 카드는 **자기 필드만** 저장한다: 저장할 때 서버의 최신 설정을 읽어 그 카드의 필드만 덮어쓴다 (네이버: `naverBlogId`, 티스토리: `tistoryBlogId`, 워드프레스: `wordpressUrl`·`wordpressCategoryId`, 모델: `models`). 그래서 한 카드의 "저장"이 다른 카드의 미저장 입력이나 새 글에서 기억된 이미지 옵션을 바꾸지 않는다 (`blog-writer:src/SettingsPanel.tsx:30-36`, `:88-105`).
- 워드프레스 연결 저장은 사이트 주소를 먼저 저장해야 한다("사이트 주소 등 바뀐 설정을 먼저 저장한 뒤 연결하세요."). 저장 전에 사이트에 실제로 인증해 본다 → [[_system/integrations/wordpress-rest]].
- 설정 화면 카드 순서: 네이버 블로그 설정, 티스토리 설정, 워드프레스 설정, 네이버 데이터랩 설정, Claude 모델 설정, Claude in Chrome(확장 연결 + 확장이 막는 블로그).

## 저장 위치
`data/settings.json`, 워드프레스 인증은 `data/secrets.json` → [[_system/configuration]], [[_system/data-storage]]
