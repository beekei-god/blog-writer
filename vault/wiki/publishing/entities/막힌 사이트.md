# 막힌 사이트 (BlockedSites)

## 의미
Claude in Chrome이 안전 정책으로 접속을 막은 블로그 플랫폼 기록. 한 번 막히면 다음부터는 Claude in Chrome을 시도하지 않고 바로 대체 경로로 간다. 크롬으로 올리는 네이버·티스토리에만 해당한다(워드프레스는 API로 올려 기록될 일이 없다. 저장 타입은 세 플랫폼을 다 허용).

## 속성
| 속성 | 타입 | 의미 | 화면 표시 |
|---|---|---|---|
| 키 | Platform | 막힌 플랫폼 | "네이버 블로그 — 평소 크롬으로 진행" (실제 경로 `fallback` 기준) |
| `at` | ISO | 처음 막힌 시각 | "(날짜에 막힘)" |
| `detail` | string ≤200 | 차단 문구 요약 | (표시 안 함) |
| `fallback` (응답에만) | `user-chrome`/`app-chrome` | 실제로 쓰는 대체 경로. 저장하지 않고 조회할 때 서버가 붙임 | 경로 문구 |

## 상태와 전이
없음 → (블로그 입력 중 `SiteBlockedError`) → 막힘 → (설정 "다음 작성 때 Claude in Chrome부터 다시 시도") → 없음 (파일 삭제).

## 저장 위치
`data/blocked-sites.json` (임시 파일 없이 바로 덮어씀 → [[publishing/open-questions]] #9)
