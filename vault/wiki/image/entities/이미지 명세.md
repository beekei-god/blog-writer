# 이미지 명세 (ImageSpec)

## 의미
이미지 한 장의 "무엇을 왜 그리는지"와 "만든 결과"를 담는다. 썸네일은 글(`post.thumbnail`)에, 본문 이미지는 글 블록(`type: image`)에 같은 모양으로 들어 있다. 이미지를 가리키는 키는 `thumbnail` 또는 `body-<블록 번호>`다.

## 속성
| 속성 | 타입 | 의미 |
|---|---|---|
| `basis` | string | 이 이미지의 근거가 된 본문 문장(글에 쓴 그대로) |
| `prompt` | string | 그릴 장면 (Claude는 한국어, Gemini/ChatGPT는 영어) |
| `headline` | string | 이미지 안에 넣을 문구 (없으면 글자 없는 그림) |
| `userEdited` | boolean | 사용자가 prompt를 직접 고쳤는지. 참이면 기획 단계가 건드리지 않음 |
| `alt` | string | 대체 텍스트 |
| `file` | string | 저장된 파일 이름 (`data/images/<작업>/…`) |
| `madeForTitle` | string | 썸네일을 만들 때의 글 제목 → [[image/business-rules/BR-IMG-007 제목 확정 후 썸네일 생성]] |
| `error`, `errorKind`, `errorProvider` | | 실패 기록 → [[image/entities/이미지 오류 종류]] |

## 상태 / 수명주기
계획됨(file 없음) → 생성 성공(file 기록, 오류 지움) 또는 실패(file 지움, 오류 기록). 새 파일이 기록된 뒤에만 예전 파일을 지운다.
