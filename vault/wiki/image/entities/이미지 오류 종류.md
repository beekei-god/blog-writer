# 이미지 오류 종류 (ImageErrorKind)

## 의미
이미지 생성이 실패한 원인 분류다. 서버가 실패와 함께 기록하고, 화면은 종류별 제목·안내(`IMAGE_ERROR_INFO`)와 "다시 만드는 방법"을 보여 준다. 원인을 아는 곳에서는 `ImageGenError(kind, …)`를 던지고, 모르는 오류는 메시지로 분류한다(`classifyImageError`).

## 속성
| 종류 | 뜻 |
|---|---|
| extension | Claude in Chrome 확장이 연결되지 않음 |
| login | 크롬에서 그 AI에 로그인 안 됨 |
| refused | 정책상 거절(지브리풍·실존 인물 등) |
| limit | 생성 한도·API 잔액 부족 |
| timeout | 시간 초과 |
| ui_changed | 사이트 화면에서 진행 못함 |
| download | 이미지는 만들었지만 파일을 못 받음 |
| browser_missing / browser_busy / browser_closed | 크롬 없음 / 사용 중 / 탭 닫힘 |
| svg_invalid | Claude의 SVG를 쓸 수 없음 |
| claude_error | Claude 호출 실패 |
| api_error | 이미지 API 오류(키 오류 포함) |
| site_error | 사이트가 "문제가 발생했습니다" 표시 |
| unknown | 그 밖 |

분류 우선순위: extension → 시간 초과 문구 → 로그인 → 크롬 닫힘/없음/사용 중 → Claude CLI(한도면 limit) → limit → refused → SVG → download → site_error → timeout → ui_changed → unknown.
