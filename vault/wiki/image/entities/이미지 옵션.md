# 이미지 옵션 (ImageOptions)

## 의미
작업을 만들 때 고른 이미지 설정이다. 작업에 저장되고, 다시 만들 때 바꿀 수 있다. 마지막으로 쓴 값은 다음 작업의 기본값으로 설정에 기억한다.

## 속성
| 속성 | 의미 |
|---|---|
| `thumbnail` | 썸네일을 만들지 여부. 새 작업에서는 꺼 두고 버튼으로 켠다 → [[image/business-rules/BR-IMG-007 제목 확정 후 썸네일 생성]] |
| `bodyImages` | 본문 이미지 개수 0~6(`MAX_BODY_IMAGES`) |
| `provider`, `style` | 본문 AI(claude/gemini/chatgpt)와 스타일(ghibli/realistic/anime/flat) |
| `thumbnailProvider`, `thumbnailStyle` | 썸네일만 다르게 → [[image/business-rules/BR-IMG-003 썸네일 AI와 본문 AI 분리]] |
| `method`, `thumbnailMethod` | api / chrome → [[image/business-rules/BR-IMG-004 API와 크롬 생성 방법]] |

해석 함수: `aiFor`(AI·스타일), `methodFor`(방법), `fitStyle`(AI가 못 그리는 스타일은 그 AI의 첫 스타일로). 기본값은 thumbnail false, 본문 0장, claude + flat.
