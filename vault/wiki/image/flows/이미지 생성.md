# 이미지 생성

## 목적
글에 정해진 이미지 자리를 실제 파일로 채운다. 범위(scope)는 all / failed / thumbnail / body-N.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 대상 모으기(`collectTargets`): 썸네일(켜짐+정보 있음)과 이미지 블록, 범위로 거름 | `images/index.ts` | [[image/business-rules/BR-IMG-001 본문 이미지 개수]] |
| 2 | 사용자가 prompt를 고친 이미지(`userEdited`)는 빼고, 나머지를 AI|스타일로 묶어 기획 | `images/plan.ts` | [[image/business-rules/BR-IMG-005 이미지 기획과 문구]] |
| 3 | Claude 이미지부터 만듦(SVG→PNG) | `images/svg.ts` | [[image/business-rules/BR-IMG-009 SVG 안전 렌더링]] |
| 4 | Gemini/ChatGPT: API 키 있고 api 방식이면 API, 아니면 크롬 | `api.ts`, `webAi.ts` | [[image/business-rules/BR-IMG-004 API와 크롬 생성 방법]] |
| 5 | 장마다 결과(파일/오류) 즉시 작업 파일에 기록, 새 파일이 저장된 뒤 예전 파일 삭제 | `record` | [[image/business-rules/BR-IMG-008 실패 기록과 계속 진행]] |
| 6 | 끝나면 `draft_ready` (한 장씩 모드는 모두 끝난 뒤) | `pipeline.ts` | [[image/business-rules/BR-IMG-010 이미지 한 장씩 다시 만들기]] |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 대상이 없음 | "만들 것이 없습니다" 로그 후 종료 | 로그 |
| 기획 실패 | 기본 장면으로 계속 | 로그 |
| 장 실패 | 오류 기록, 다음 장 계속 | 이미지별 오류 안내 |
| 중지 | 실패 기록 없이 멈춤 | "중지했습니다" |
