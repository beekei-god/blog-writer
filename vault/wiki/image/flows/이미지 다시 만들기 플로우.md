# 이미지 다시 만들기 플로우

## 목적
실패했거나 마음에 들지 않는 이미지를 다른 AI·화풍으로 다시 만들거나, 직접 올린 이미지로 바꾼다. 다른 이미지는 건드리지 않는다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 화면이 대기 중인 편집을 먼저 저장(`flush`) | `src/job/JobDetail.tsx` | |
| 2a | 실패 안내: 원인별 설명과 권하는 AI 선택 → "실패한 N개를 ○○로 다시 만들기" | `ImageFailures` | [[image/business-rules/BR-IMG-012 실패 후 다른 AI 추천]] |
| 2b | 이미지별: AI·화풍 고르고 "○○로 다시 만들기" (이 이미지에만 적용). 대상 키는 `thumbnail` 또는 `body-<블록 번호>` | `ImageTools` (`src/job/images.tsx`) | [[image/business-rules/BR-IMG-009 다시 만들기 범위]] |
| 2c | 썸네일 없는 글: AI 고르고 "썸네일 만들기" | `thumb-missing` | |
| 2d | "직접 올리기" → 파일 선택 → 바이너리 업로드 → 바로 교체 | `ImageTools`, `POST /images/:target` | [[image/business-rules/BR-IMG-010 직접 올리기 형식과 크기]] |
| 3 | 서버: 진행 중 409, 조합 검증, 옵션 저장(한 장은 저장 안 함), `markBusy(generating_images)`, `runImages(scope)` → 202 | `server/routes/images.ts` | [[image/business-rules/BR-IMG-002 AI별 허용 스타일]] |
| 4 | 이미지 생성 | | [[image/flows/이미지 생성 플로우]] |
| 5 | 끝나면 `draft_ready`. 화면은 job.updatedAt이 바뀌면 초안을 다시 받음 | `doImages` | |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 진행 중 | 409 | 오류 배너 |
| 불가 조합 | 400 | 오류 배너 |
| 대상 블록 사라짐 | 404 | "화면을 새로고침해 주세요." |
| 생성 실패 | 실패 기록, draft_ready | 실패 안내 갱신 |
