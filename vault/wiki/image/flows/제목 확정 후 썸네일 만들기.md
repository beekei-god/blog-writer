# 제목 확정 후 썸네일 만들기

## 목적
썸네일 문구와 장면이 사용자가 고른 최종 제목과 맞도록, 제목이 정해진 뒤에 썸네일을 만든다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 초안 완성(썸네일 없음) → 화면이 "썸네일이 없습니다" 안내 | 화면 | [[image/business-rules/BR-IMG-007 제목 확정 후 썸네일 생성]] |
| 2 | (선택) 제목 후보 다시 만들기·직접 수정 | | [[writing/flows/제목 후보 다시 만들기]] |
| 3 | 버튼 → `regenerate-images` `{addThumbnail, thumbnailProvider/Style/Method}` | `routes/images.ts` | [[image/business-rules/BR-IMG-003 썸네일 AI와 본문 AI 분리]] |
| 4 | 기본 썸네일 정보 저장, `thumbnail` 범위로 생성 시작 | `pipeline.ts` | |
| 5 | 기획이 제목·본문을 보고 문구(질문)·장면 결정 | `plan.ts` | [[image/business-rules/BR-IMG-006 썸네일 문구는 질문만]] |
| 6 | 생성 후 `madeForTitle` 기록 | `record` | |
| 7 | 이후 제목이 바뀌면 "제목이 바뀌었습니다" + 다시 만들기 안내 | 화면 | |
