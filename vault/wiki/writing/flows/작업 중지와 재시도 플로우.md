# 작업 중지와 재시도 플로우

## 목적
오래 걸리는 작업을 멈추거나, 처음부터 다시 만들거나, 지운다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | "작업 중지" 확인 창 → `POST /cancel` | `JobDetail.cancel`, `blog-writer:server/routes/jobs.ts:183-190` | |
| 2 | `cancelJob`: 그 작업의 AbortController를 모두 abort (이미지를 한 장씩 동시에 만드는 중이면 여러 개). 없으면 409 | `cancel.ts` | [[image/business-rules/BR-IMG-014 한 장씩 다시 만들기 동시 실행]] |
| 3 | 실행 중 `runClaude`가 신호를 받아 CLI를 SIGTERM → `CancelledError`. 워드프레스 API 요청도 같은 신호로 끊긴다 | `claude.ts`, `server/wordpress.ts` | |
| 4 | 파이프라인 catch에서 상태 결정 | `pipeline.ts` | [[writing/business-rules/BR-WRT-012 중단 시 작업 상태 복구]] |
| 5 | "다시 시도"(초안 없음)·"자료 조사부터 다시 하기"(초안 있음, 확인 창: 지금 초안이 새 초안으로 바뀜) → `POST /retry` → `researching`, `runDraft` | `JobDetail.retry`, `blog-writer:server/routes/jobs.ts:192-202` | [[writing/flows/초안 작성 플로우]] |
| 6 | "삭제" 확인 창 → `DELETE /jobs/:id` → job 파일과 이미지 폴더 삭제 | `store.deleteJob` | [[writing/business-rules/BR-WRT-011 작업 중복 실행과 진행 중 변경 금지]] |
