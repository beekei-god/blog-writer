# 제목 후보 다시 만들기

## 목적
글은 그대로 두고 제목 후보 3개만 새로 받는다. 썸네일이 이미 있는 글에서 제목을 바꾸면 화면이 "이 제목으로 썸네일 다시 만들기"를 보여 준다. → [[image/overview]]

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 초안 있음, 진행 중 아님 확인 | `routes/jobs.ts` | |
| 2 | 작업의 규칙 사본(없으면 현재 규칙)으로 호출 | | [[writing/business-rules/BR-WRT-009 글쓰기 규칙 문서와 작업별 사본]] |
| 3 | 제목 기법 6가지·키워드 규칙으로 후보 3개 | `titles.ts` | [[writing/business-rules/BR-WRT-005 제목 후보와 후킹 기법]] |
| 4 | 후보만 응답. 글 저장은 화면의 자동 저장 | | |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 초안 없음 | 400 | "초안이 없습니다" |
| 진행 중 | 409 | 끝난 뒤 다시 |
| 후보 없음 | 오류 | "제목 후보를 만들지 못했습니다" |
