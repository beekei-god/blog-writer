# 프롬프트로 글 고치기

## 목적
글을 직접 편집하지 않고 요청 문장으로 고치되, 결과를 비교한 뒤 사용자가 적용 여부를 정한다.

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 요청 검사, 진행 중 작업 확인(409) | `routes/edit.ts` | [[writing/business-rules/BR-WRT-011 프롬프트로 글 고치기]] |
| 2 | `editProposal.status=running` 저장, 백그라운드 실행 | `pipeline.ts:startEdit` | |
| 3 | 이미지는 ref로 숨기고 Claude가 새 블록 생성 (필요 시 웹 검색·열람 ≤4) | `editPost.ts:proposeEdit` | [[writing/business-rules/BR-WRT-004 키워드 횟수와 검색 의도]] |
| 4 | 이미지 복원 검사, 불완전 표 제거, 바뀐 것 없으면 거절 | `proposeEdit` | |
| 5 | `ready`로 저장 → 화면이 고치기 전·후 비교 표시 | `shared/blockDiff.ts` | |
| 6 | 적용: 그 범위의 글이 안 바뀌었을 때만 교체 | `applyProposal` | |
| 7 | 버리기: `DELETE /edit` | | |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| Claude 실패 | 제안 `failed`(글은 그대로) | 오류 문구 |
| 중지 | 제안이 사라짐 | |
| 제안 후 그 범위를 직접 고침 | 적용 거절(409) | "같은 요청으로 다시 만들어 주세요" |
| 서버 재시작 중 running | `failed` | "글 고치기가 중단되었습니다" |
