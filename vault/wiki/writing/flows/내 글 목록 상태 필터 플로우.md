# 내 글 목록 상태 필터 플로우

## 목적
글이 많아졌을 때 상태별로 골라 본다 (예: 아직 발행하지 않은 임시저장 글, 실패한 글).

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 칩 7개를 보여 준다: 전체 / 진행 중 / 초안 완료 / 임시저장 완료 / 예약됨 / 발행 완료 / 실패. 칩마다 해당 글 개수 | `App` `FILTERS` (`blog-writer:src/App.tsx:23-34`) | [[writing/entities/Job]] |
| 2 | 칩을 누르면 `filter` 상태가 바뀌고 목록이 `matchesFilter`로 걸러진다 | `App` (`:36`, `:106`) | |
| 3 | "진행 중"은 `BUSY_STATUSES`(자료 조사·글 작성·이미지 생성·크롬 작성) 전체를 묶은 것이고, 나머지는 상태 하나와 같다 | `matchesFilter` | |
| 4 | 목록 머리글: 전체면 "N개", 필터 중이면 "보이는 수 / 전체 수개". 해당 글이 없으면 "이 상태의 글이 없습니다." 글마다 상태 배지(`STATUS_LABEL`, 상태별 색: 예약됨은 별도 색 `--sch`, 발행 완료는 보라색 `--pub`) | `App` (`:132`, `:150-153`, `:166`), `blog-writer:src/styles.css:91-97` | |
| 5 | 폴링으로 상태가 바뀌면(예: 진행 중 → 초안 완료) 칩 개수와 목록이 바로 갱신된다 | `App` 1.5초 폴링 (`:88`) | [[writing/flows/초안 작성 플로우]] |

## 예외 / 경계값
- 필터는 화면 상태일 뿐 저장하지 않는다. 새로고침하면 "전체"로 돌아간다.
- 필터 때문에 현재 보고 있는 글이 목록에서 사라져도 상세 화면은 그대로 열려 있다 (선택은 `selectedId`로 따로 관리).
- 서버·API 변경은 없다 (목록은 `GET /api/jobs` 전체를 받아 화면에서 거른다).
