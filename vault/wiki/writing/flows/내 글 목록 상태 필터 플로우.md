# 내 글 목록 상태 필터 플로우

## 목적
글이 많아졌을 때 글 작성 단계별로 골라 본다 (예: 아직 검토하지 않은 초안, 임시저장만 한 글).

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 칩 5개를 보여 준다: 전체 / 자료 조사 중 / 초안 검토 / 임시 저장 / 발행 완료. 칩마다 해당 글 개수 | `App` `FILTERS` (`blog-writer:src/App.tsx:26-33`) | [[writing/entities/Job]] |
| 2 | 칩을 누르면 `filter` 상태가 바뀌고 목록이 `matchesFilter`로 걸러진다 (칩의 `statuses`에 글 상태가 들어 있으면 보임, `statuses`가 없는 "전체"는 모두 보임) | `App` (`blog-writer:src/App.tsx:35-38`, `:108`) | |
| 3 | 칩과 상태 묶음 (아래 표). 실패(`failed`)한 글은 어느 묶음에도 없어서 "전체"에서만 보인다 | `FILTERS` | |
| 4 | 목록 머리글: 전체면 "N개", 필터 중이면 "보이는 수 / 전체 수개". 해당 글이 없으면 "이 상태의 글이 없습니다." 글마다 상태 배지(`statusLabel` = `STATUS_LABEL`, 상태별 색: 진행 중은 주황, 초안 검토는 강조색, 임시저장 완료는 초록, 발행 예약은 청록 `--sch`, 발행완료는 보라 `--pub`, 실패는 빨강) | `App` (`blog-writer:src/App.tsx:134`, `:151-155`, `:168`), `blog-writer:src/styles.css:91-97` | |
| 5 | 폴링으로 상태가 바뀌면(예: 자료 조사 중 → 초안 검토) 칩 개수와 목록이 바로 갱신된다 | `App` 1.5초 폴링 (`blog-writer:src/App.tsx:90`) | [[writing/flows/초안 작성 플로우]] |

| 칩 (`key`) | 묶는 상태 | 배지 이름 |
|---|---|---|
| 전체 (`all`) | 모든 상태 (실패 포함) | |
| 자료 조사 중 (`researching`) | `researching`, `writing`, `generating_images` — 초안이 나오기 전 | 자료 조사 중 / 글 작성 중 / 이미지 생성 중 |
| 초안 검토 (`draft`) | `draft_ready` | 초안 검토 |
| 임시 저장 (`saved`) | `posting`, `posted` | 블로그 임시저장 중 / 블로그 임시저장 완료 |
| 발행 완료 (`published`) | `scheduled`, `published` | 블로그 발행 예약 / 블로그 발행완료 |

## 예외 / 경계값
- 필터는 화면 상태일 뿐 저장하지 않는다. 새로고침하면 "전체"로 돌아간다.
- 필터 때문에 현재 보고 있는 글이 목록에서 사라져도 상세 화면은 그대로 열려 있다 (선택은 `selectedId`로 따로 관리).
- 실패한 글만 따로 보는 칩은 없다 (2026-10-09에 "실패" 칩이 없어짐).
- 칩 이름("임시 저장", "발행 완료")은 배지 이름("블로그 임시저장 완료", "블로그 발행완료")과 글자가 조금 다르다.
- 서버·API 변경은 없다 (목록은 `GET /api/jobs` 전체를 받아 화면에서 거른다).
