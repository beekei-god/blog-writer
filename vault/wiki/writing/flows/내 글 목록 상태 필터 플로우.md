# 내 글 목록 상태 필터 플로우

## 목적
글이 많아졌을 때 블로그별로, 글 작성 단계별로 골라 본다 (예: 네이버에 아직 안 올린 초안, 워드프레스에 임시저장만 한 글).

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 블로그 칩 4개: 전체 블로그 / 네이버 / 티스토리 / 워드프레스. 그 아래 상태 칩 5개: 전체 / 자료 조사 중 / 초안 검토 / 임시 저장 / 발행 완료. 상태 칩마다 **고른 블로그 기준** 개수 | `App` `BLOG_FILTERS`·`FILTERS` (`blog-writer:src/App.tsx:27-35`, `:136-151`) | [[writing/entities/Job]] |
| 2 | 칩을 누르면 `blogFilter`·`filter` 상태가 바뀌고 목록이 `matchesFilter(job, blog, filter)`로 걸러진다 | `App` (`blog-writer:src/App.tsx:57`, `:108`), `blog-writer:shared/blogStatus.ts:36-43` | |
| 3 | 묶는 기준 (아래 표). 블로그를 고르면 **그 블로그에서의 위치**(`blogPositionOf`: 올리는 중 / 올리지 않음 / posted·scheduled·published)로, 전체 블로그면 어느 블로그든 해당하면 보인다. 실패(`failed`)한 글은 "전체"에서만 보인다 | `blog-writer:shared/blogStatus.ts:6-11`, `:24-43` | |
| 4 | 목록 머리글: 전부 보이면 "N개", 일부만 보이면 "보이는 수 / 전체 수개". 해당 글이 없으면 "이 상태의 글이 없습니다." | `App` (`blog-writer:src/App.tsx:134`, `:184`) | |
| 5 | 글마다 배지: 올린 블로그가 있는 초안은 **블로그별 배지만**("네이버 발행완료", "워드프레스 임시저장 완료" …), 진행 중·실패이거나 올린 블로그가 없으면 글 상태 배지(`statusLabel`)도 함께. 배지는 한 묶음으로 줄을 바꿔 가며 놓이고, 날짜는 줄바꿈 없이 오른쪽에 | `App` (`blog-writer:src/App.tsx:158-172`), `blog-writer:src/styles.css:76-78` | |
| 6 | 배지 색: 진행 중 주황, 초안 검토 강조색, 임시저장 완료 초록, 발행 예약 청록 `--sch`, 발행완료 보라 `--pub`, 실패 빨강 | `blog-writer:src/styles.css:94-99` | |
| 7 | 폴링으로 상태가 바뀌면(예: 자료 조사 중 → 초안 검토, 올리는 중 → 네이버 임시저장 완료) 칩 개수와 목록이 바로 갱신된다 | `App` 1.5초 폴링 (`blog-writer:src/App.tsx:90`) | [[writing/flows/초안 작성 플로우]] |

| 상태 칩 (`key`) | 블로그를 고름 (예: 네이버) | 전체 블로그 |
|---|---|---|
| 전체 (`all`) | 모든 글 (실패 포함) | 모든 글 (실패 포함) |
| 자료 조사 중 (`researching`) | 초안이 나오기 전 (`researching`·`writing`·`generating_images`), 블로그와 관계없음 | 같음 |
| 초안 검토 (`draft`) | 초안이 있고 글이 `draft_ready`·`posting`이며 **그 블로그에 아직 안 올린** 글 (다른 블로그에 올리는 중이어도 포함) | 초안이 있고 **어느 블로그에도** 안 올린 글 |
| 임시 저장 (`saved`) | 그 블로그에 올리는 중이거나 그 블로그가 `posted` | 어느 블로그든 올리는 중이거나 `posted` |
| 발행 완료 (`published`) | 그 블로그가 `scheduled`·`published` | 어느 블로그든 `scheduled`·`published` |

## 예외 / 경계값
- 필터는 화면 상태일 뿐 저장하지 않는다. 새로고침하면 "전체 블로그 · 전체"로 돌아간다.
- 필터 때문에 현재 보고 있는 글이 목록에서 사라져도 상세 화면은 그대로 열려 있다 (선택은 `selectedId`로 따로 관리).
- 한 글이 블로그마다 다른 칩에 들어갈 수 있다. 전체 블로그에서는 네이버 발행완료·워드프레스 임시저장 완료인 글이 "임시 저장"과 "발행 완료" 둘 다에 보인다.
- 실패한 글만 따로 보는 칩은 없다 (2026-10-09에 "실패" 칩이 없어짐).
- 칩 이름("임시 저장", "발행 완료")은 배지 이름("임시저장 완료", "발행완료")과 글자가 조금 다르다.
- 서버·API 변경은 없다 (목록은 `GET /api/jobs` 전체를 받아 화면에서 거른다). 예전 글은 서버가 읽을 때 블로그별 상태로 옮겨 보낸다 → [[writing/entities/Job]].
