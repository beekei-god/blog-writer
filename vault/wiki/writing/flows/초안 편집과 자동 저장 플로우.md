# 초안 편집과 자동 저장 플로우

## 목적
사용자가 초안을 검토·수정하고, 수정이 서버에 빠짐없이 저장되게 한다. (예전에 있던 "글 복사"는 2026-10-09에 없어졌다 → 아래 10단계)

## 단계
| # | 단계 | 위치 | 관련 규칙 |
|---|---|---|---|
| 1 | 편집 탭: 제목, 태그(Enter/쉼표로 추가, 빈 칸 Backspace로 삭제), 썸네일·블록별 편집, 블록 삭제(확인 창) | `PostEditor`, `TagInput`, `ImageEditor` (`src/job/PostEditor.tsx`) | [[writing/business-rules/BR-WRT-004 태그 최대 30개]] |
| 2 | 표는 "한 줄=한 행, 칸은 `|`, 첫 줄은 머리글", 목록은 한 줄=한 항목 | `PostEditor` | [[writing/business-rules/BR-WRT-007 빈 칸 있는 표 행 제거]] |
| 3 | 이미지 문구·설명을 고치면 `userEdited: true` | `ImageEditor` | [[image/business-rules/BR-IMG-006 직접 고친 이미지 보호]] |
| 4 | 입력을 멈추고 1초 뒤 `PUT /api/jobs/:id/post`. 저장은 체인으로 하나씩, 저장 중 새 수정이 오면 다시 대기 | `edit`, `flush` (`blog-writer:src/job/JobDetail.tsx:42-70`) | |
| 5 | 서버: 진행 중이면 409, 스키마 검증, 이미지 `file`/`error`는 서버 값 유지(`keepImageResults`), 불완전한 표 행 제거 | `blog-writer:server/routes/jobs.ts:85-99`, `:17-39` | [[image/business-rules/BR-IMG-008 이미지 결과는 서버 기록 우선]], [[writing/business-rules/BR-WRT-011 작업 중복 실행과 진행 중 변경 금지]] |
| 6 | 저장 상태 표시: 저장됨 / 저장 중… / 저장 실패. 저장 안 됐으면 창 닫기 경고 | `JobDetail` | |
| 7 | 다른 화면으로 가면 남은 수정을 저장 | unmount effect | |
| 8 | 블로그 등록·이미지 다시 만들기·한 장 다시 만들기·올리기 전에는 먼저 `flush` | `postToBlog`, `regenerate`, `imageTools` (`:103-140`) | |
| 9 | 서버 쪽 초안이 바뀌면(이미지 완성 등) 편집 대기분이 없을 때만 화면 초안 교체 | `useEffect([job.updatedAt])` | |
| 1a | 편집 모드 블록 앞 체크박스로 "프롬프트로 고칠 부분"을 고름(카드는 `EditByPrompt`). 블록 수가 바뀌면 선택 해제 | `PostEditor` `selection`, `blog-writer:src/job/JobDetail.tsx:176-180` | [[writing/flows/프롬프트로 글 고치기 플로우]] |
| 1b | 블록 사이마다 "＋ 여기에 이미지 추가"(앞뒤가 이미지이거나 6장이면 숨김·비활성) → `POST /api/jobs/:id/images`. 이미지 블록의 ×는 "이미지 삭제"(확인 창, 파일도 삭제) → `DELETE /api/jobs/:id/images/:target`. 둘 다 먼저 `flush()`로 편집 내용을 저장한 뒤 서버 API를 부른다(서버가 블록 번호를 정함) | `PostEditor`, `blog-writer:src/job/JobDetail.tsx:136-150` | [[image/overview]] |
| ~~10~~ | ~~복사: 본문(서식 HTML+텍스트), 텍스트만, 제목, 태그. 이미지는 `[썸네일]`, `[이미지 n: 설명]` 자리 표시~~ — **deprecated (2026-10-09)**: 복사 막대(`CopyBar`)와 복사용 변환(`postToHtml`/`postToText`), 복사용 스타일이 코드에서 삭제됨. 글은 앱이 블로그에 직접 올리는 경로(임시저장·예약발행·자동발행)로만 내보낸다 | (삭제됨, 커밋 65bfa3e) | [[publishing/flows/블로그 임시저장 플로우]] |

## 실패 / 예외 경로
| 상황 | 결과 | 사용자에게 보이는 것 |
|---|---|---|
| 스키마 위반(태그 31개 이상 등) | 400, 대기분 유지 | "자동 저장 실패: 글 형식이 올바르지 않습니다." |
| 진행 중 저장 | 409 | "자동 저장 실패: 작업 진행 중에는 수정할 수 없습니다." (진행 중엔 편집 탭이 비활성이라 드묾) |
| 프롬프트로 글 고치기 제안을 만드는 중 저장(`PUT /post`) | 409 (같은 `isRunning` 검사). 화면은 `busy`로 편집을 막는다 | 편집 비활성, 안내 "프롬프트로 글을 고치는 중입니다…" → [[writing/business-rules/BR-WRT-017 고친 결과 적용 조건과 잠금]] |
| 이미지 추가·삭제 중 작업 진행 | 409 "진행 중인 작업이 끝난 뒤에 추가해 주세요."/"…삭제해 주세요." | 오류 문구 |
| 작업 삭제 | 대기 타이머·대기분 버림 | |
