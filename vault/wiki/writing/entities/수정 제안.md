# 수정 제안 (EditProposal)

## 의미
"프롬프트로 글 고치기"의 결과를 글에 바로 넣지 않고 작업 안에 임시로 둔 것이다. 사용자가 고치기 전·후를 비교해 보고 적용하거나 버린다. 작업당 하나만 둘 수 있다.

## 속성
| 속성 | 의미 |
|---|---|
| `status` | running / ready / failed |
| `prompt`, `range?` | 수정 요청과 고칠 블록 범위(없으면 글 전체) |
| `writing?` | 분량·말투 다시 쓰기일 때의 새 옵션 → [[writing/business-rules/BR-WRT-012 분량 말투 다시 쓰기]] |
| `before`, `after` | 범위의 고치기 전·후 블록 |
| `title?`, `summary?` | 글 전체를 고칠 때의 새 제목·요약 |
| `note` | 무엇을 어떻게 고쳤는지 한두 문장 |
| `charsBefore`, `charsAfter` | 본문 글자수 변화 |
| `error` | 실패 이유 |

## 상태 / 수명주기
running → ready(결과 있음) → 적용 또는 버림. 서버 재시작 중 running이면 failed로 바꾼다. 실패해도 글은 그대로다.
