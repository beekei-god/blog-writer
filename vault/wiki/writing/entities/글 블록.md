# 글 블록 (PostBlock)

## 의미
글 본문을 이루는 조각이다. 화면 편집기, 미리보기, 블로그별 붙여넣기 HTML(네이버·티스토리)과 워드프레스 블록이 모두 이 목록을 읽어 만든다.

## 속성
| 종류 | 내용 | 글자수에 포함 | 비고 |
|---|---|---|---|
| `heading` | 소제목 text | 포함 | 앞에 이모지 하나 |
| `paragraph` | 문단 text (문장마다 `\n`) | 포함 | `**굵게**`만 허용 |
| `list` | items[] | 항목마다 포함 | |
| `quote` | 인용 text | 포함 | |
| `table` | headers[], rows[][] | 칸마다 포함 | 빈 칸 행은 제거 → [[writing/business-rules/BR-WRT-006 확인된 사실만 쓰기]] |
| `place` | name, address? | 제외 | → [[writing/business-rules/BR-WRT-008 장소 블록]] |
| `image` | basis, prompt, headline, alt, file … | 제외 | → [[image/overview]] |

"참고 자료"(또는 "출처") 소제목부터 끝까지는 글자수와 키워드 횟수에서 제외한다(`REFERENCE_HEADING`). 글자수는 `**` 표시와 줄바꿈을 빼고 이모지·한글을 한 글자로 센다.
