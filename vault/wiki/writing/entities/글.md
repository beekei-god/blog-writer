# 글 (Post)

## 의미
작업 안에 들어 있는 블로그 글 본문 데이터다. 제목·요약·본문 블록 목록·태그·키워드와, 제목 후보·이미지 정보를 가진다. 서버는 zod 스키마(`PostSchema`)로 저장 전에 모양을 검사한다.

## 속성
| 속성 | 타입 | 의미 | 화면 표시 |
|---|---|---|---|
| `title` | string | 선택한 제목 | 제목 칸 |
| `titleCandidates` | string[] | 제목 후보 3개 → [[writing/business-rules/BR-WRT-005 제목 후보와 후킹 기법]] | 후보 목록 |
| `summary` | string | 글 요약 | 요약 칸 |
| `blocks` | [[writing/entities/글 블록]][] | 본문 | 편집기 |
| `tags` / `tagDetails` | string[] / {tag, source, query} | 태그와 근거 → [[writing/business-rules/BR-WRT-007 태그 수와 출처 확인]] | 태그 표 |
| `tagsCheckedAt` | 날짜 | 태그 확인 날짜 | |
| `searchQuestion` | string | 이 글이 답하는 검색 질문 | |
| `mainKeyword` / `subKeywords` | string / string[] (2~3) | 키워드 → [[writing/business-rules/BR-WRT-004 키워드 횟수와 검색 의도]] | 키워드 횟수 표 |
| `omittedItems` | string[] | 확인 못 해 본문에서 뺀 항목 | 안내 |
| `thumbnail` | ImageSpec | 썸네일 정보 → [[image/overview]] | |
