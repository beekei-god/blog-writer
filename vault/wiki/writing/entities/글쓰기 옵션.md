# 글쓰기 옵션 (WritingOptions)

## 의미
글을 만들 때 사용자가 고르는 값이다. 작업(Job)에 저장되어 그 글을 고치거나 다시 쓸 때도 기준이 된다. 마지막으로 쓴 값은 설정에 기억해 다음 작업의 기본값이 된다(단, 경험 메모는 기억하지 않는다).

## 속성
| 속성 | 타입 | 의미 | 화면 표시 |
|---|---|---|---|
| `targetChars` | 정수 1,000~8,000 | 본문 목표 글자수. 프리셋 짧게 1,500 / 보통 2,500 / 길게 4,000 / 아주 길게 6,000 | 분량 선택 |
| `tone` | info/friendly/story/summary | 정보형·친근형·스토리형·정리형 → [[writing/business-rules/BR-WRT-002 말투와 문장 끝 검사]] | 말투 선택 |
| `format` | info/review (선택) | 글 형식 → [[writing/business-rules/BR-WRT-003 글 형식과 경험 메모]] | 글 형식 |
| `experience` | string ≤1,500자 (선택) | 리뷰용 경험 메모 | 경험 메모 칸 |

기본값은 2,500자 + 정보형(`DEFAULT_SETTINGS.writing`). 옵션이 없는 예전 작업은 2,500자 목표·3,000자 상한이고 말투 검사를 하지 않는다.
